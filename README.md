# GAMES DASHBOARD

This project is a follow up from the countries dashboard project that I had done before. Because I no longer had access to the API key and the right amount of data I decided to do another project and try to make slight improvements on the previous one. This project has better methods of parsing the JSON data in a more manageable way and searching for a specific item can be done in more than 1 way. This one also others more functionality with the wishlist as users are able to add the games to other types of lists rather than 1 unified wish list

This project was made on Intellij idea and uses Java and Java swing for the user interface.

This is currently still being developed.
